# ゲームの登録方法

`games-data.js` の `window.portfolioGames = [ ... ];` に作品情報を追加します。
HTMLや表示用JavaScriptの変更は不要です。初期表示は `developmentOrder` の昇順です。

## 並べ替えと分類

- 「タグ絞り込み」で登録済みのタグを選択できます。初期値はAND（選択タグをすべて含む）で、OR（いずれかを含む）へ切り替えられます。切り替えは即時反映され、選択タグは維持します。該当作品を先頭に表示し、非該当作品は薄く後ろに表示します（クリックして詳細を開くことも可能）。分類中は各分類内で優先表示し、該当・非該当それぞれの中で開発時期順を維持します。タグ未選択なら全作品が該当します。「選択を解除」でタグ選択をクリアできます。

- 初期表示の「開発時期↓」は新しい順です。「開発時期↑」は古い順（小さい値から）で、クリックすると反転します。
- `developmentOrder` に非表示の数値を設定します。連番や年など、全作品で同じ基準を使ってください。同じ値は登録順、未指定はどちらの方向でも最後になります。
- 「利用エンジン」は作品数の多いエンジン順、同数は日本語の辞書順で分類します。
- 「開発人数」は `teamSizeCount` の大きい順に分類します。省略時は `teamSize` の `"3人"`、`"3"`、`"個人制作"` などから判定します。判定できないものは「未設定」として最後に表示します。
- 各分類内でも開発時期順を維持します。選択中の分類を再度クリックすると分類を解除します。

## 登録例

画像を `games/images/` に置き、次の項目をコピーして配列内へ追加します。
各作品の末尾の `},` を忘れないでください。

```js
    {
        title: "ゲームのタイトル",
        image: "images/my-game.webp",
        imageAlt: "森のステージを探索するゲーム画面",
        detailImage: "images/my-game-large.webp",
        tags: ["アクション", "Unity", "個人制作"],
        engine: "Unity",
        teamSize: "3人",
        developmentPeriod: "2025年4月〜2025年8月",
        developmentOrder: 2025,
        teamSizeCount: 3,
        introductionPath: "information/my-game/introduction.txt",
        detailsPath: "information/my-game/details.txt",
    },
```

- `title`: ゲームタイトル。
- `image`: 一覧用画像。正方形に切り抜いて表示するため、正方形画像がおすすめです。
- `imageAlt`: 詳細画像の内容を説明する代替テキスト。
- `detailImage`: 詳細用の1920×1080px画像を指定します。表示枠は16:9で、画面に合わせて縮小します。異なる比率の画像は余白を付け、切り抜かず表示します。画像ファイルそのものを1920×1080pxに変換する処理はありません。省略または空文字なら `image` を使います。
- `tags`: 自由なタグ一覧。不要なら `[]` にします。
- `engine`: 利用エンジン。例：`"Unity"`、`"Unreal Engine 5"`。空欄の場合は「未設定」と表示します。
- `teamSize`: 開発人数。例：`"個人制作"`、`"3人"`。空欄の場合は「未設定」と表示します。
- `developmentPeriod`: 開発時期。例：`"2025年4月〜2025年8月"`。空欄の場合は「未設定」と表示します。
- `introductionPath`: 「ゲーム紹介」タブに表示するTXTファイルのパス。
- `detailsPath`: 「詳細」タブに表示する開発時の説明のTXTファイルのパス。

文章はUTF-8で保存したTXTファイルに直接書きます。改行や空行はそのまま表示され、HTMLとしては解釈しません。
例えば `games/information/my-game/` に `introduction.txt` と `details.txt` を作成します。
パス未指定または空のTXTは「準備中」、読み込みに失敗した場合はエラー文を表示します。
TXTの読み込みにはHTTPサーバーが必要です。HTMLの直接ダブルクリックではなく、下記のローカルURLから確認してください。

画像のパスは `/games/` からの相対パスです。大文字・小文字も実際のファイル名に合わせてください。
フォルダーの区切りには、Windows上でも `\` ではなくWeb用の `/` を使用してください。
画像が空欄、または読み込めない場合は「画像準備中」と表示します。
TXT内ではバッククォートなどの記号もそのまま記述できます。
全作品を消して配列を `[]` にすると準備中メッセージを表示します。

## 表示の確認

プロジェクトのルートで `python -m http.server 8000` を実行し、
`http://localhost:8000/games/` を開いてください。
作品カードを押すと詳細が開き、閉じるボタン・Escキー・背景のクリックで閉じられます。
PCでは画面に合わせた大きさの詳細枠に、左側は画像とタグ、右側はタイトルとスクロール可能な説明を表示します。
スマートフォンでは縦に並びます。説明欄はキーボードでもスクロールできます。
